# ALL-VideoDownload-Plus

## 中文

这是私有分发仓库中的源码项目占位目录，**不是 OpenWrt 软件包**，这里没有
`opkg` / `apk` 软件源。

请从私有 GitHub 仓库获取源码：

```sh
git clone git@github.com:smthdagg/ALL-VideoDownload-Plus.git
cd ALL-VideoDownload-Plus
```

然后按照项目 README 使用本地 Docker 或 VPS Docker 部署。不要把本目录加入
`/etc/opkg/customfeeds.conf`。

## English

This is a source-only placeholder. It is **not an OpenWrt package** and has no
`opkg`/`apk` feed here.

Clone the private GitHub repository:

```sh
git clone git@github.com:smthdagg/ALL-VideoDownload-Plus.git
cd ALL-VideoDownload-Plus
```

Follow the project README for local Docker or VPS Docker deployment. Do not add
this directory to `/etc/opkg/customfeeds.conf`.
