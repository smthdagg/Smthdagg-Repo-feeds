# XShield

## 中文

这是私有分发仓库中的源码项目占位目录，不是 OpenWrt 软件包，不应使用
`opkg` 或 `apk` 安装。

通过 Git SSH 克隆私有项目仓库：

```sh
git clone git@github.com:smthdagg/XShield.git
cd XShield
```

然后按照项目 README 执行实际运行和部署步骤。

## English

This is a source-only placeholder. It is not an OpenWrt package and must not be
installed with `opkg` or `apk`.

Clone the private project repository over Git SSH:

```sh
git clone git@github.com:smthdagg/XShield.git
cd XShield
```

Follow that repository's README for the actual runtime and deployment steps.
